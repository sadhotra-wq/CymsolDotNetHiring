# Hiring.MVC5Layer

This repository contains a 5-layer ASP.NET MVC 5 (.NET Framework 4.7.2) solution scaffold for a developer screening exercise.

## Candidate Task
You will receive failing unit tests and must make them pass by changing production code only.

## Build
1. Open `Hiring.MVC5Layer.sln` in Visual Studio.
2. Restore NuGet packages.
3. Build the solution.
